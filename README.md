# PECS Template
## Setup
- Install Playdate SDK
- Add Playdate SDK path to Windows Env Variables
- Clone this
- Clone https://github.com/notpeter/playdate-luacats.git in the same root folder
- Open VSCode
- Install recommended extensions
- Edit source/pdxinfo

## Resources
- https://sdk.play.date/3.0.1/Inside%20Playdate.html

## How to use
- Press F5 to debug
- Press Ctrl + Shift + B to build
